# Student Grade Calculator

A beginner-friendly Python program that calculates a student's total marks, percentage, and grade.

## Features

- Takes student's name as input
- Accepts marks for 5 subjects
- Calculates total marks
- Calculates percentage
- Assigns a grade based on percentage

## Technologies Used

- Python

## How to Run

Run the following command:

python student_grade_calculator.py

## Example

Input:
- Student Name: Nikita
- Subject Marks: 80, 75, 90, 90, 80

Output:
- Total Marks: 415
- Percentage: 83%
- Grade: A
